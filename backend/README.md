# ReadmeAI - Gemini README Generator

An AI-powered README generator that creates professional Markdown
documentation for software projects using the Gemini API.

## Features

- Generate README documentation using AI
- Simple project details form
- Markdown preview
- Copy generated documentation
- Download README.md
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Google Gemini API
